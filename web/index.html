03 / The field notebook

    Source notes / Read before interpreting

    A specification is a promise,
    not a measurement.

    What gets compared

    Method and exact path identify an operation. Changes cover authentication, deprecation, inherited parameters, request bodies, responses, server addresses and documentation. Local schema references are followed, including recursive references.

    Arrays retain their order except security alternatives, scopes and merged parameters. Reordering examples or schema alternatives can therefore appear as a structural change.

    What these dates mean

    “Captured” is when this project fetched a definition. “Directory updated” comes from APIs.guru and can be much older. Directory versions may represent different API generations; they are not necessarily a complete history or the provider's current release.

    The initial capture has no earlier collection baseline. Multiple listed versions can still be compared. Weekly collection adds future observations without rewriting earlier ones.

    Where the evidence comes from

    APIs.guru OpenAPI Directory supplies the public definitions and their original-source links. Each definition retains its source license metadata. OpenAPI describes the format.

    External references, callbacks and webhooks are not resolved or compared as standalone operations. We do not assess exploitability, runtime behaviour or whether a change is safe for your client. No credentials or target-service requests are used.
